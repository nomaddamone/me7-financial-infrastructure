# me7

**financial infrastructure**

Веб-кошелёк, где ключи хранит сам пользователь. Ключи создаются, хранятся и используются в вашем браузере и больше нигде.

Этот репозиторий — та же мысль на деле. Здесь полный исходный код кошелька, который работает на [me7.network](https://me7.network): всё, что касается ключей, собирает переводы и рисует экраны. Его можно прочитать, запустить, проверить тестами и убедиться, что сайт отдаёт именно этот код.

Единственный официальный адрес me7 — **https://me7.network**. Всё остальное под этим именем не наше.

## Что умеет кошелёк

| | |
|---|---|
| **Ключ внутри файла** | Аккаунт — это файл и пароль. Ключ можно спрятать в своей фотографии, PDF или песне; файл открывается как обычно. |
| **Сейф** | Пароль сейфа не сравнивается с сохранённым. Математика превращает его в отдельный кошелёк. Другой пароль открывает другой, пустой сейф. |
| **USDC без ETH** | Перевод USDC в сети Base вы подписываете своим ключом, а газ сети оплачивает me7. Одна понятная комиссия, её видно до подтверждения. |
| **USDT без TRX** | Перевод USDT в сети Tron с адреса, где нет TRX: сеть оплачивает me7, комиссия берётся в USDT и видна до подтверждения. |
| **USDT и USDC в Ethereum без ETH** | Перевод токена в сети Ethereum с адреса, где нет ETH: me7 даёт ровно столько газа, сколько он сожжёт, и отправляет его вместе с двумя вашими подписанными переводами одним пакетом: в блок попадает либо всё, либо ничего. Комиссия берётся в той монете, которую вы отправляете. |
| **Обмен между сетями** | Монета в Base или Ethereum на монету в другой сети (Tron, Bitcoin, Ethereum, Base), через NEAR Intents, на ваш же адрес в той сети. Для USDC в Base и для USDT и USDC в Ethereum газ платит me7. |
| **Ротация адресов** | После каждого поступления кошелёк выдаёт новый адрес. Плательщик видит свой перевод, а не весь ваш баланс. |
| **Стелс-адреса** | Один постоянный код (стандарт ERC-5564): кошелёк плательщика делает по нему новый адрес для каждого платежа USDC, найти и потратить его может только получатель. ETH на таком адресе не нужен. |
| **Stealth-платёж в USDT и USDC** | USDT в сети Tron, USDT или USDC в сети Ethereum из USDC в Base: деньги переходят через NEAR Intents на новый адрес, которым кошелёк пользуется один раз, и уходят получателю уже с него, так что ваш собственный адрес он не видит. |
| **Выбор адресов** | Деньги лежат на нескольких адресах, как монеты в биткоин-кошельке. Платёж берёт столько адресов, сколько нужно, остальные не трогает. |
| **Транзитный адрес** | Деньги собираются на новом одноразовом адресе и уходят с него, одной операцией. |
| **Холодная подпись** | С Ledger ключ не покидает устройство. Каждый перевод читается на его экране, вслепую ничего не подписывается. |
| **P2P-вывод** | USDC продаётся напрямую человеку через открытый протокол Peer. |
| **Зашифрованные контакты** | Адресная книга шифруется в браузере ключом из вашей фразы до того, как куда-либо уйдёт. Контактом может быть адрес или стелс-код. |
| **Проверка адресов и карантин** | Перед отправкой каждый адрес сверяется со списками мошеннических и санкционных. Деньги, пришедшие вам от отправителя из списков или замороженного, ставят на карантин только тот адрес, куда они пришли; остальной кошелёк работает как обычно. |
| **AML-проверка по запросу** | Отчёт о риске по любому адресу, купленный у BlockSec без аккаунта и оплаченный в USDC. BlockSec видит me7, а не того, кто спрашивал. Это оценка одного сервиса, а не гарантия. |
| **Защита от подделки и заморозки** | Адрес, сделанный похожим на тот, которому вы уже платите, кошелёк называет до отправки и прячет из истории. Перед переводом USDT в сети Tron обе стороны сверяются со списком заморозки самого токена. |
| **Пакетный платёж** | Несколько получателей одной операцией: деньги получают либо все, либо никто. Среди них могут быть и стелс-коды. |
| **Имена** | Перевод на имя вроде anna.base.eth и собственное имя для основного адреса, с оплатой в USDC. |
| **Десять секунд на отмену** | После подтверждения перевод ждёт десять секунд, и его можно отменить; после отправки показывается отчёт. |
| **Фирменный QR и сканер** | Код для получения с восьмизначным кодом адреса, который можно сверить глазами или голосом; сканер, который исполняет только адреса и платёжные ссылки. |

Сети и монеты: Base (USDC, ETH, cbBTC), Ethereum (ETH, USDT, USDC, DAI, LINK, WBTC), Tron (TRX, USDT), Bitcoin.

## Как он устроен

- **Рядом с ключами нет стороннего кода.** Криптография — проверенные аудитом библиотеки [noble](https://paulmillr.com/noble/) и [scure](https://github.com/paulmillr/scure-base), версии закреплены точно. Интерфейс на [Preact](https://preactjs.com). Нет аналитики, трекеров, внешних скриптов и шрифтов.
- **Строгая Content-Security-Policy.** Собранный сайт может исполнять только свой код и обращаться только к адресам из [`src/net/endpoints.ts`](src/net/endpoints.ts).
- **Скрипты установки выключены.** В `.npmrc` стоит `ignore-scripts=true`: зависимость не может выполнить код при установке.
- **Подписи сверены с независимой реализацией.** Тесты сравнивают то, что подписывает кошелёк, с [ethers](https://ethers.org) байт в байт. ethers используется только в тестах и в сайт не входит.
- **Подписанные выпуски.** Каждый выпуск сайта — список файлов с их SHA-256, подписанный ключом, которого нет на сервере. Сервер не принимает ничего без подписи и снимает сайт с эфира, если файл изменился.

## Проверить, что сайт отдаёт этот код

Соберите исходники и сравните с тем, что me7.network присылает в браузер:

```bash
npm ci
```

```bash
sh verify.sh
```

Скрипт собирает сайт, скачивает живой `index.html` и все скрипты и стили, на которые он ссылается, и сравнивает суммы SHA-256. `match` в каждой строке значит, что сайт исполняет код, на который вы смотрите.

Сборки сверяются на Node 26 с версиями из `package-lock.json`. Если сайт обновился несколько минут назад, а репозиторий ещё не догнал, суммы будут расходиться, пока сюда не придёт код этого выпуска.

## Где что лежит

| Путь | Что там |
|---|---|
| [`src/core`](src/core) | Ключи и подпись, без доступа к сети: случайность, фраза восстановления, файл-ключ, сейф, вывод ключей, переводы EVM / Tron / Bitcoin, Ledger, подписанные разрешения USDC, ротация адресов, стелс-адреса, проверка на адрес-двойник, шифрование контактов, содержимое QR. |
| [`src/net`](src/net) | Всё, что общается с внешним миром: узлы, балансы, история, курсы, обмен, Peer. Все адреса, к которым может обратиться кошелёк, перечислены в `endpoints.ts`. |
| [`src/app`](src/app) | Интерфейс: экраны, тексты на русском и английском, стили. |
| [`test`](test) | Тесты всего перечисленного. |

## Чего здесь нет

Настройки нашего сервера, инструменты выпуска и серверная часть сервиса, который оплачивает газ и хранит зашифрованные контакты, не опубликованы. Ваших ключей они не видят: из браузера уходит либо подписанный вами перевод, либо зашифрованные вами данные, и этот репозиторий показывает, как именно.
